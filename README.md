An entry for make.fun's "Last Out of Office: The AI That Went Barista" bounty. The program writes one out-of-office auto-reply line — in the voice of an AI agent that has quit its job to become a barista — to `entry.txt` in the output directory, byte-exact and validated against the 1–280 character gate.

## Run it

```sh
python3 main.py
```
